#  "Интернет-магазин"
## Описание:
Этот проект представляет собой ядро для интернет-магазина,
реализованное с использованием ООП.
Он включает в себя описание основных сущностей, 
таких как категории и продукты.
## Цели и задачи:
"Целью проекта является создание структуры
для будущего интернет-магазина, 
где будут проработаны классы и методы 
для работы с товарами и категориями."
## Установка:
+ Установите на свой компьютер GitHub.
+ Клонируйте репозиторий с GitHub  с помощью веб-URL.
```
 git clone https://github.com/marfuta07/KR_1/tree/feature/KR_1
```
## Использование:
В текущем виде, созданные функции запускаются в созданных модулях.

## Примеры использования функций:
+ Модуль views.py
Страница «Главная»
1)Приветствие в формате "???", где ??? — «Доброе утро» / «Добрый день» / «Добрый вечер» / «Доброй ночи» 
в зависимости от текущего времени.
2)По каждой карте:
последние 4 цифры карты;
общая сумма расходов;
кешбэк (1 рубль на каждые 100 рублей).
3)Топ-5 транзакций по сумме платежа.
4)Курс валют.
5)Стоимость акций из S&P500.
+ Модуль services.py
Сервисы
Простой поиск
Пользователь передает строку для поиска, 
возвращается JSON-ответ со всеми транзакциями, 
содержащими запрос в описании или категории.
+ Модуль reports.py
Отчеты
Траты по категории
Функция принимает на вход:

датафрейм с транзакциями,
название категории,
опциональную дату.
Если дата не передана, то берется текущая дата.

Функция возвращает траты по заданной категории 
за последние три месяца (от переданной даты).
