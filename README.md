#  "Интернет-магазин"
## Описание:
Этот проект представляет собой ядро для интернет-магазина,
реализованное с использованием ООП.
Он включает в себя описание основных сущностей, 
таких как категории и продукты.
## Цели и задачи:
"Целью проекта является создание структуры
для будущего интернет-магазина, 
где будут проработаны классы и методы 
для работы с товарами и категориями."
## Установка:
+ Установите на свой компьютер GitHub.
+ Клонируйте репозиторий с GitHub  с помощью веб-URL.
```
 git clone https://github.com/marfuta07/Homework_14_1/tree/feature/homework_14_1
```
## Использование:
"Для запуска проекта необходимо клонировать репозиторий,
установить зависимости с помощью poetry 
и запустить скрипт main.py."
## Примеры использования функций:
+ Модуль category.py

Для класса Category  определите следующие свойства:
название (name),
описание (description),
список товаров категории (products)
количество категорий
количество товаров
+ Модуль product.py

Для класса Product  определите следующие свойства:
название (name),
описание (description),
цена (price),
количество в наличии (quantity).

## Разработка:
+ Проект находится в активной разработке. План работы в дальнейшем:
   + Добавление новых модулей для расширения функционала
